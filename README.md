# 🗡️ Elden Ring: Arquivo das Terras Intermédias

Este repositório contém a documentação técnica e estratégica para atingir **100% de conclusão** em Elden Ring. O foco principal é garantir a **Platina | Conquistas** em uma única jornada (save), evitando a perda de conteúdos temporários (*missables*).

## 🎯 Escopo do Guia 

Para garantir a progressão perfeita, cada diretório deste guia cobre:

* **NPC Questlines:** Roteiro de diálogos e ações para não "quebrar" missões de personagens (ex: Ranni, Alexander, Millicent).
* **Inventory Protocol:** Localização de todos os itens da região:
    * **Lendários:** Armamentos, Talismãs, Feitiços e Encantamentos (obrigatórios para conquistas).
    * **Upgrades:** Sementes Douradas, Lágrimas Sagradas e Pedras de Forja.
    * **Coletáveis:** Sinos de Invocação, Cinzas de Guerra e Livros de Receitas.
* **Boss Registry:** Checklists divididos entre:
    * **Principais (Legacy):** Chefes que concedem Lembranças ou Conquistas.
    * **Secundários:** Chefes de Campo e de Masmorras (Dungeons/Cárceres) para obtenção de loot específico.
